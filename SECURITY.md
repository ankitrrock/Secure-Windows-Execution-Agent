# Security model

## Threat model

The service treats n8n inputs, repository content, process output, and model output as untrusted. Its purpose is constrained automation under the current Windows user's privileges. It does not defend against compromise of that account, administrator-level malware, or tampering by a local administrator.

## Controls

- **Authentication:** 48 bytes of cryptographic random material generated by the installer; bearer token compared in constant time. It is stored outside the project tree with a user-only Windows ACL.
- **Authorization:** centralized registry; only declared tool names and strict Pydantic input schemas are callable. No generic execution endpoint exists.
- **Commands:** only internally selected `git`, `node`, `npm`, `code`, and `schtasks`; resolved from PATH, invoked with argument arrays and `shell=False`, bounded timeouts/output, and sanitized errors.
- **Filesystem:** `%USERPROFILE%\Tools\OmniRoute` only. Absolute/drive/UNC/traversal paths and symlink escapes are rejected. File reads are size-limited.
- **Secrets:** allowlisted names only; `secret.set` uses Windows Credential Manager. There is no secret retrieval tool. Secret values are not logged. The application does not expose environment dumps.
- **Network:** loopback bind by default and enforced in configuration. n8n remote connectivity requires a private authenticated tunnel/VPN; never open a public firewall port.
- **Abuse limits:** 60 API requests/minute per client in memory, 64 KiB request limit, bounded network/process timeouts, sanitized API errors, and local JSONL audit events.
- **Repository integrity:** clone URL is a literal official GitHub repository, no arbitrary URL. `git.status` precedes user-directed repository changes; no reset/clean operation exists.
- **Extensions:** only the official Google Gemini Code Assist and OmniRoute OmniCopilot marketplace IDs are accepted.

## Remaining risks and limitations

Loopback HTTP has no TLS; a local process under the same user may be able to access the token file. Windows Credential Manager support depends on a functioning keyring backend. The first npm package installation executes upstream package lifecycle scripts as the current user; supply chain trust remains a user decision. The audit log is not tamper-resistant. Rate limiting is per process and restart resets it. `scheduler.create/remove` are safe no-ops pending an independently reviewed agent startup task implementation. OmniRoute configuration/provider credentials remain managed in OmniRoute's own UI. Public network access via n8n must be implemented with a secure private tunnel outside this service.

## Reporting

Do not submit secrets or sensitive logs in security reports. Include the affected version and a minimal reproduction.
